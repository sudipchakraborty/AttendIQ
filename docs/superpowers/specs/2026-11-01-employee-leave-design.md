# Employee leave review version

Approved in chat on 2026-11-01. Employees sign in and submit SL or CL with a start date and whole number of calendar days. Each sees only their own applications and annual balances. Admin alone sees all applications, approves/rejects pending requests and changes allowances in Admin Settings. SL=10 and CL=10 initially, per calendar year, without carry-forward. Approved requests consume allowance; pending requests are displayed separately. Reject overlapping pending/approved requests and approvals exceeding the allowance. Split cross-year leave into separate requests. Changes to allowances apply to the selected year; do not allow reductions below already approved usage.

Use the existing React/MUI shell with dedicated Leave and Admin Settings routes. Corporate layout: summary cards, application form, searchable/filterable table, clear status badges and empty/error/loading states. Employees land on Leave after login. Admin has report access plus leave administration. HR/Viewer receive no access to other employees' leave.

Approach: local Node HTTP service with private JSON storage, hashed passwords and cookie sessions; no Contabo connections. This was recommended over browser-only storage because browser filtering cannot enforce record privacy, and over the existing database backend because the client requested JSON first. Opt-in local-review runtime keeps the existing standalone calculator and connected production mode intact. A checked-in JSON seed defines review accounts and allowances; mutable data is under ignored .attendiq/leave-review. Demo account credentials are documented and limited to this local review service, which binds to loopback.

Server permissions derive from authenticated identity, never submitted employee IDs. Validate dates, integers, ownership, status transitions and allowance updates on the service. Serialize mutations and atomically replace JSON to avoid lost updates. Record approver and timestamps. Private files are never served by Vite. Database migration, Contabo deployment, carry-forward, accrual and half-days are outside this review scope.
